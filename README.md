# ONYX 💎

> **ONYX** — ультрабыстрый, легковесный десктопный плеер для SoundCloud с поддержкой YouTube Music, текстов песен, Discord RPC и 10-полосного эквалайзера.

Построен на **Rust + Tauri v2** с нативным интерфейсом без тяжелого Chromium/Electron.

---

## ⚡ Особенности

- 🎧 **Воспроизведение без лагов:** нативный стриминг SoundCloud и YouTube Music
- 🖤 **Премиум-дизайн:** темные темы (Pure OLED, Wine Glow, Midnight, Obsidian)
- 📝 **Синхронизированные субтитры:** караоке-тексты песен в реальном времени (LRCLIB & Genius)
- 🎚️ **10-полосный эквалайзер:** студийная настройка звука и пресеты
- 🎮 **Discord Rich Presence:** показ трека, артиста и обложки в статусе Discord
- 🐧 **Linux First:** полная поддержка Linux (AppImage, deb, Arch) без подвисаний
- 💾 **Автономность:** сохранение лайков и сессии даже в гостевом режиме
- 🪟 **Минимализм:** легковесный бинарник (~14 MB), потребляет в 5-10 раз меньше RAM, чем браузер
