# 🎵 SoundCloud Desktop Player

Стильный, быстрый и функциональный десктопный клиент для **SoundCloud**, созданный на базе **Tauri v2** и современного веб-стека.

---

## ✨ Основные возможности

* **🌊 Моя волна (Умный радиопоток):**
  * Бесконечный персональный поток музыки по вкусу на базе ваших лайков и алгоритмов SoundCloud.
  * Настроения и фильтры: *Всё подряд*, *Бодрое*, *Спокойное*, *Любимое*, *+ Новое*.
  * Автоматическое непрерывное пополнение потока свежими рекомендациями.

* **🎨 Темы оформления и кастомизация:**
  * **Pure OLED Black (`#000000`)** по умолчанию — идеальный глубокий чёрный цвет для OLED-экранов.
  * **Clean Light Mode (`#f8fafc`)** — выверенная светлая тема с правильным контрастом и читаемыми кнопками.
  * Палитра цветовых акцентов (включая чистый белый `#ffffff`, графитовый `#000000`, неон, аметист, изумруд).
  * Настройка прозрачности интерфейса, размытия стекла (Glassmorphism) и пользовательских обоев.

* **🔒 Авторизация и профиль:**
  * Вход через удобное диалоговое окно SoundCloud, внешний браузер или по никнейму/ID/OAuth токену.
  * Надёжное локальное сохранение сессии и медиатеки между перезапусками.
  * Быстрая синхронизация любимых треков.

* **🎤 Синхронизированные слова песен (Lyrics):**
  * Интеграция с **LRCLIB** (построчные караоке-тексты) и **Genius**.
  * Полноэкранный иммерсивный плеер с визуализатором.

* **🎮 Discord Rich Presence:**
  * Отображение текущего играющего трека, исполнителя, обложки и статуса воспроизведения в Discord.

* **🔍 Мульти-поиск:**
  * Поиск треков через SoundCloud, YouTube Music и Яндекс Музыку в едином интерфейсе.

* **🎛️ 10-полосный эквалайзер:**
  * Готовые пресеты (Bass Boost, Vocal, Electronic, Flat и др.) и тонкая ручная регулировка.

## 🚀 Быстрый старт и сборка

### Требования
* [Rust](https://www.rust-lang.org/) (версия 1.75+)
* [Node.js](https://nodejs.org/) (версия 18+)
* MinGW-w64 (GCC / Clang) для Windows

### Сборка
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/soundcloud-desktop.git
   cd soundcloud-desktop
   ```
2. Запустите сборку:
   ```cmd
   build.bat
   ```
   Собранный исполняемый файл `SoundCloud.exe` появится в корневой папке.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| <kbd>Space</kbd> | Воспроизведение / Пауза |
| <kbd>→</kbd> / <kbd>L</kbd> | Перемотка вперёд (+5 сек) |
| <kbd>←</kbd> / <kbd>J</kbd> | Перемотка назад (-5 сек) |
| <kbd>Shift</kbd> + <kbd>→</kbd> | Следующий трек |
| <kbd>Shift</kbd> + <kbd>←</kbd> | Предыдущий трек |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Регулировка громкости (+5% / -5%) |
| <kbd>M</kbd> | Отключить / включить звук (Mute) |
| <kbd>S</kbd> | Перемешать очередь (Shuffle) |
| <kbd>R</kbd> | Повтор одного трека (Repeat) |
| <kbd>F</kbd> | Полноэкранный режим / Текст песни |
| <kbd>Q</kbd> | Боковая панель текущей очереди |
