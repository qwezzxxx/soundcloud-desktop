# soundcloud-desktop

Десктопный клиент для SoundCloud на базе Tauri и Rust.

## Возможности
- Поддержка SoundCloud, YouTube Music и Яндекс Музыки
- «Моя волна» и умные рекомендации треков
- Синхронизированные построчные караоке-тексты (LRCLIB, Genius)
- 10-полосный эквалайзер с пресетами
- Настраиваемые темы оформления (Pure OLED, Light, Wine Glow и др.)
- Выбор акцентных цветов интерфейса
- Discord Rich Presence
- Глобальные горячие клавиши

## Установка
Скачайте готовый архив в [Releases](https://github.com/qwezzxxx/soundcloud-desktop/releases), распакуйте в любую папку и запустите `SoundCloud.exe`.

## Сборка
Для сборки из исходников требуются:
- Rust (1.75+)
- MinGW-w64 (GCC)

Запуск сборки:
```cmd
build.bat
```
Исполняемый файл появится в корне: `SoundCloud.exe`.

## Управление
| Клавиша | Действие |
| :--- | :--- |
| `Space` | Воспроизведение / Пауза |
| `→` / `←` | Перемотка (5 сек) |
| `Shift + →` / `Shift + ←` | Следующий / предыдущий трек |
| `↑` / `↓` | Громкость (+5% / -5%) |
| `M` | Заглушить звук |
| `S` | Перемешать очередь |
| `R` | Повтор трека |
| `F` | Полноэкранный плеер с текстом |
| `Q` | Открыть очередь воспроизведения |
